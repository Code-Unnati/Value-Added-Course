A structured collection of learning materials, hands-on exercises, and notes from my **Value Added Course**, covering enterprise technology and next-gen computing concepts.

## 📚 Course Modules

This repository is organized by topic. Each folder contains code samples, notes, and practice exercises related to that module.

| Module | Description |
|---|---|
| 🟧 **SAP BTP** | SAP Business Technology Platform fundamentals — services, cloud application development, integration, and extensibility on BTP. |
| 🟦 **SAP ABAP** | Core ABAP programming — syntax, OOP (classes/interfaces), CRUD operations, database handling (Open SQL), loops, conditionals, and ABAP Cloud (Steampunk) development using `IF_OO_ADT_CLASSRUN`. |
| 📊 **SAP Analytics Cloud (SAC)** | Dashboards, data modeling, planning, and predictive analytics using SAP's cloud-based BI and planning platform. |
| ☁️ **Cloud Computing (AWS)** | Core AWS services and cloud architecture concepts — EC2, S3, IAM, deployment models, and hands-on labs using Amazon Web Services. |
| 📡 **Edge Computing (Raspberry Pi Pico, ESP32)** | Embedded systems and IoT development using Raspberry Pi Pico and ESP32 — sensor integration, microcontroller programming, and edge data processing. |

## 🚀 Getting Started

### Prerequisites
- **SAP BTP / ABAP**: Access to an SAP BTP trial account with ADT (ABAP Development Tools) installed in Eclipse, or SAP Business Application Studio.
- **SAC**: An SAP Analytics Cloud tenant (trial or licensed).
- **Cloud Computing (AWS)**: An AWS Free Tier account.
- **Edge Computing**: Raspberry Pi Pico and/or ESP32 board, USB cable, and Arduino IDE / MicroPython/Thonny IDE for programming.

### Cloning the Repository
```bash
git clone https://github.com/<your-username>/Value-Added-Course.git
cd Value-Added-Course
```
